# The War Room

A fantasy football draft companion that scores every player under **your league's actual
rules** rather than a generic PPR list.

Four leagues are built in, each with its own ADP board, roster requirements, lineup slots
and strategy notes. Projected points and value-over-replacement are recomputed per league,
so the same player is priced differently in a 6-point-passing-TD league than in a standard
one — which is the whole point.

- **Big Board** — 200 players, natural-break tiers, projections, VOR, watchlist
- **Draft** — mock simulator, live tracker, and live sync from Sleeper's public API
- **My Team** — starters, bench, bye conflicts, roster requirements
- **Depth Charts** — ADP-implied pecking order for all 32 teams
- **Intel** — sleepers, breakouts and busts with reasoning
- **Plan** — strategy written for each league's specific rules

Data: ADP from Fantasy Football Calculator; projections, live draft picks and exact league
scoring from Sleeper's public API. No projections are invented — where a rule cannot be
derived from season totals (per-game bonus ladders), the app says so instead of guessing.

Single self-contained HTML file. Installable, works offline.
